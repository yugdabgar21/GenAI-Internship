# GenAI Internship

Work record of my Generative AI internship. It shows what I built and what I learned while working with large language models.

## What I worked on

I started with basic model calls and moved to prompt design for daily use cases. I wrote short scripts that take a clear input and return a clean result. Each script fixed a small task end to end.

## Day structure

| Day | Work |
| --- | --- |
| Day1 | Mistral quickstart, tokens and transformers notes |
| Day2 | Sentiment prompts and tokenization notes |
| Day3 | Hinglish and Gujlish dare generator |
| Day4 | Task1 support reply, Task2 product description |
| Day5 | Task3 email classifier, Task4 meeting actions |
| Day6 | Task5 social post, Task6 code explainer |
| Day7 | Task7 translator, Task8 cover letter |
| Day8 | Task9 moderation, Task10 interview questions |
| Day9 | Task11 review sentiment, Task12 quiz generator |
| Day10 | JSON review parser |
| Day11 | Streaming demo and flashcard generator |
| Day12 | Customer support dashboard, resume screener, AI content studio |

Every day folder runs on its own. Put a `.env` file inside the folder with `MISTRAL_API_KEY` before running a script. The `.env` files stay out of git.

## Skills I used

* Prompt design with role and output shape stated in plain words.
* Review of outputs across tones and levels so replies fit the case.
* Careful test runs with sample inputs before marking a task done.

## Outcome

This repo holds my full task set from the internship period.
